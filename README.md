# Vue Intermedio (VUE_INT)

## Plataforma de laboratorios

Te damos la bienvenida a la plataforma de laboratorios del curso Vue Intermedio. Aquí aplicarás reactividad, Composition API, enrutamiento, gestión del estado, comunicación con servicios, rendimiento, pruebas y despliegue mediante prácticas guiadas con Vue.

## Lista de laboratorios

Haz clic en el título de cada práctica para abrir su guía en GitHub Pages. Las descripciones corresponden a la columna «Qué construyes» del README original del repositorio.

## Capítulo 1

### [Práctica 1.4: diagnóstico y optimización de dibujos en una SPA](https://netec-mx.github.io/VUE_INT/Capitulo01/)

- Descripción: Catálogo que mide sus propios dibujos y los baja de 12 a 1 con `computed`, props y `shallowRef`
- ⏱️ Duración estimada: 24 min.

## Capítulo 2

### [Práctica 2.4: refactorizar componentes a Composition API y crear composables](https://netec-mx.github.io/VUE_INT/Capitulo02/)

- Descripción: Lista de tareas que pasa de Options API a composables, `provide`/`inject` con `Symbol` y un componente sin interfaz
- ⏱️ Duración estimada: 30 min.

## Capítulo 3

### [Práctica 3.4: flujo de autenticación con rutas protegidas y carga dinámica](https://netec-mx.github.io/VUE_INT/Capitulo03/)

- Descripción: Inicio de sesión simulado con guardias, roles, rutas anidadas y carga perezosa con recuperación de errores
- ⏱️ Duración estimada: 46 min.

## Capítulo 4

### [Práctica 4.4: diseñar y aplicar una arquitectura de stores para una aplicación compleja](https://netec-mx.github.io/VUE_INT/Capitulo04/)

- Descripción: Varias stores de Pinia que colaboran, con un plugin propio de persistencia y acciones asíncronas
- ⏱️ Duración estimada: 46 min.

## Capítulo 5

### [Práctica 5.4: clientes REST y GraphQL con manejo de caché y errores](https://netec-mx.github.io/VUE_INT/Capitulo05/)

- Descripción: Cliente REST con Axios y cliente GraphQL con Apollo sobre un servidor simulado (MSW, Mock Service Worker), con caché normalizada y errores unificados
- ⏱️ Duración estimada: 46 min.

## Capítulo 6

### [Práctica 6.4: aplicar optimizaciones y medir mejoras en una SPA real](https://netec-mx.github.io/VUE_INT/Capitulo06/)

- Descripción: Medición antes y después: división de código, carga diferida y análisis del paquete
- ⏱️ Duración estimada: 46 min.

## Capítulo 7

### [Práctica 7.4: crear una estrategia de pruebas para una aplicación Vue](https://netec-mx.github.io/VUE_INT/Capitulo07/)

- Descripción: Pruebas unitarias y de componentes con Vitest y recorridos de punta a punta con Cypress
- ⏱️ Duración estimada: 46 min.

## Capítulo 8

### [Práctica 8.4: diseñar y desplegar una aplicación escalable con pipeline automatizado](https://netec-mx.github.io/VUE_INT/Capitulo08/)

- Descripción: Monorrepositorio con pnpm, imagen de Docker y flujo de integración continua en GitHub Actions
- ⏱️ Duración estimada: 43 min.
